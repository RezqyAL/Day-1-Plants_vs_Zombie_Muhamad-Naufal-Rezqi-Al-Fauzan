Deskripsi singkat repository (berdasarkan materi “From AI to GitHub”):

Repository (repo) itu tempat nyimpen satu proyek lengkap sama riwayat perubahannya. Isinya file proyek (kode, gambar, dokumen) plus folder .git yang nyatet siapa ngubah apa dan kapan. Repo bisa ada di laptop sendiri (lokal) dan bisa juga online di GitHub.

Di materi ini, repo yang dibikin adalah repo buat proyek Student Task Planner, yaitu web app sederhana (HTML, CSS, dan JavaScript) yang dibuat pakai bantuan AI lewat prompt yang spesifik. Alurnya:

– Bikin repo baru lewat git init, atau ambil dari GitHub pakai git clone "url"
– Pindahin perubahan ke staging pakai git add .
– Simpan perubahan pakai git commit -m "message"
– Kirim ke GitHub pakai git push origin main, dan ambil update pakai git pull origin main

Fungsinya:
– Nyimpen semua file proyek rapi di satu tempat
– Ngelacak riwayat perubahan, jadi bisa balik ke versi sebelumnya kalau ada yang salah
– Memudahkan kerja bareng karena banyak orang bisa ngerjain proyek yang sama
– Jadi backup di GitHub, jadi kodemu aman walau laptop bermasalah

Tujuan dari Sesi :

Menjelaskan bagaimana prompt AI yang lebih spesifik menghasilkan hasil yang lebih baik Mengidentifikasi repository, commit, branch, dan pull request Membedakan Git dan GitHub Melakukan version controlling

Definisi: Prompt = instruksi/masukan ke model AI untuk mendapat hasil tertentu (bisa pertanyaan, kata kunci, instruksi rumit, atau potongan kode) Prompt engineering = cara merancang instruksi agar jawaban AI tepat, relevan, dan layak dipakai

Context is key: Tanpa konteks: “Create student task planner” → hasil umum dan tidak terarah Dengan konteks: ada tujuan, requirements, constraints, dan output yang jelas → hasil lebih sesuai

Prompt Engineering: Prompt yang spesifik dan punya konteks menghasilkan jawaban AI yang lebih tepat. Struktur yang baik: Role, Task, Context, Format.

Git vs GitHub: Git = alat version control di komputer lokal. GitHub = platform online untuk menyimpan repo Git dan berkolaborasi.

Git Workflow: Perubahan bergerak dari Working directory → Staging area → Repository lewat add lalu commit.

Command Penting: git init git add . git commit -m lalu git push / git pull untuk sinkron dengan GitHub.
